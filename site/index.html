One-stop setup

Four steps. Walk away.

Set it up once and every new Claude Code session is covered. One toast per session.

1
Install
Grab it with Homebrew:
brew install --cask ZichengWangdrzz/clinotify/clinotify

Or download the DMG and drag CLINotify to Applications.

2
Hook it up
Register the agent hooks:
clinotify install

Or use the menu bar → Install Hooks. New Claude Code sessions auto-register.

3
Keep it running
Relaunch at login and across reboots:
clinotify autostart on

Toggle it any time: off | status. Keeping autostart on also means upgrades take effect immediately — the new version relaunches itself.

4
Walk away
You get a toast the moment your agent finishes or needs you. That's it.

A waving crab, a blue bubble, a green OK, a sound. In every terminal.

Reference

Commands

Everything you can do from the CLI. Skins are customizable too.

clinotify install        # register Claude Code hooks
clinotify launch         # start the menu-bar helper now
clinotify autostart on   # relaunch at login + across reboots
clinotify test           # fire a sample toast to check it works
clinotify status         # show hooks, autostart + running state
clinotify list           # list active sessions being watched
clinotify settings       # open preferences (sound, position, skin)
clinotify uninstall      # remove hooks, symlink + autostart agent
clinotify help           # show all commands
Stay current

Updating

One command. Your hooks, skins, sounds and autostart all survive the upgrade.

Upgrade to the latest release:

brew update && brew upgrade --cask clinotify

With clinotify autostart on the new version relaunches itself the moment the upgrade finishes — nothing else to do. Without autostart, run clinotify launch once after upgrading.

Upgrading from v0.1.0 or v0.1.1? Run clinotify install once after the upgrade (one-time hook migration), and expect a single password prompt during that upgrade only.

No hard feelings

Uninstall, just as easy

Run one command to clean up everything:

clinotify uninstall

Removes the Claude Code hooks, the CLI symlink, and the autostart agent.

Then drag CLINotify out of Applications — or:

brew uninstall --cask clinotify

Works in every terminal

Ghostty, iTerm2, Apple Terminal, kitty, WezTerm, the VS Code terminal, and inside tmux — because the toast is its own screen window.
