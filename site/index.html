Quick start

1 · Install Homebrew: brew install --cask ZichengWangdrzz/clinotify/clinotify — or download the DMG and drag CLINotify to Applications.
2 · Launch Open CLINotify from Applications. It lives in the menu bar (look for the CLI item) — there's no Dock icon.
3 · Hook it up Run clinotify install (or use the menu → Install Hooks). New Claude Code / Codex sessions then register themselves automatically.
4 · Keep it running Run clinotify autostart on so the helper relaunches at login and across logout/reboot — that's what makes "walk away" survive a reboot. (off to stop, status to check.)

Commands you'll actually type

clinotify install            # install the CLI + Claude Code & Codex hooks
clinotify launch             # start the menu-bar app
clinotify autostart on       # keep it running across logout/reboot (off | status)
clinotify test               # fire a test toast (try: clinotify test attention --label "Need input")
clinotify status             # channel, helper state, and paths
clinotify list               # registered sessions
clinotify settings           # show every effective setting
clinotify uninstall          # remove the Claude/Codex hooks + the clinotify CLI symlink
clinotify help               # full list (help --all shows the hook internals)

Uninstall — just as easy

clinotify uninstall          # removes the Claude/Codex hooks, the CLI symlink, and the autostart agent

Then drag CLINotify out of Applications to the Trash. Installed with Homebrew? Run clinotify uninstall first, then brew uninstall --cask clinotify — the cask also quits the helper and removes the autostart agent. (Only want to stop auto-launch but keep the app? clinotify autostart off.)

Make it yours — skins

Four independent axes. Run a verb with no value to list the options (some are paid); pass an id to set it.

clinotify animation [<id>]   # crab animation  → right-hand-wave, squint-leg-wave
clinotify bubble    [<id>]   # bubble style    → windows-xp, classic-pixel   (alias: skin)
clinotify sound     [<id>]   # sound           → glass, ping, submarine, arcade-chime

clinotify background [on|off]    # show/hide the card behind the toast
clinotify mute [on|off|toggle]   # mute this terminal's sound
clinotify scale [50%-200%]       # toast size
clinotify alerts [on|off]        # master on/off for all toasts
clinotify license                # license status / activate-local <key> / reset

License & pricing

The core experience is free — everything above: the menu-bar helper, the hooks, and a toast on every Claude Code / Codex event. A few skins and sounds are a paid upgrade (CLINotify is a commercial product, licensed via Lemon Squeezy). Manage your license from the CLI:

clinotify license                        # show license status
clinotify license activate-local <key>   # activate a purchased key

Paid skins show as locked until a key is activated. Purchase links are coming soon — the free core needs no license.

Works in every terminal — Ghostty, iTerm2, Apple Terminal, kitty, WezTerm, the VS Code terminal, and inside tmux — because the toast is its own screen window, never drawn inside the terminal.
